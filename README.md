# finish-first

아이디어에서 출고(ship)까지만 책임지는 Claude 스킬.

AI 덕분에 프로젝트를 시작하는 비용은 0에 수렴했다. 그래서 시작만 10개 쌓인다.
이 스킬은 Claude가 당신의 이탈 패턴을 차단하도록 만드는 규칙 문서다.
설치했다는 것 자체가 "나를 막아달라"는 요청이며, Claude는 그 요청을 근거로
정중하되 단호하게 규칙을 적용한다.

## 대상

바이브 코딩으로 사이드 프로젝트를 빠르게 시도하지만,
셋업 단계에서 흥미를 느끼고 마무리 전에 이탈하는 패턴을 아는 사람.

## 핵심 구조: 1사이클 = 1출고

- **스코프 확정**: 이번 사이클에 세상에 내보낼 것 1개
- **마감 확정**: 구체적 날짜·시각 (첫 사이클은 반나절 이내)
- **출고**: 배포·발행·전송. localhost는 세상이 아니다
- **회고**: 방향 재평가는 오직 여기서만

고도화가 필요하면 사이클을 다시 돈다.

## 규칙 요약

1. **사이클 밖에서는 기획하지 않는다** — 스코프·마감 확정 전엔 설계 논의 금지
2. **인프라 해금 조건** — 자동화·CI/CD·리팩토링·"나중에 필요할" 기능은
   3사이클 완료 + 실제 3회 반복된 고통에 한해서만
3. **"이게 맞나" 프로토콜** — 사이클 중 방향 논의 금지, 스코프 반토막 후 출고
4. **분석 루프 차단** — "왜 나는 못 끝내는가" 류 메타 논의 2턴 초과 시 차단

## 설치

Claude.ai: 대화에 `finish-first.skill` 파일을 올리고 Save skill 클릭.
Claude Code: 이 레포의 `finish-first/` 폴더를 스킬 디렉토리에 복사.

## 이 레포 자체가 첫 출고물이다

이 스킬은 스킬 자신의 규칙에 따라 만들어졌다.
반나절 스코프, 날짜 마감, 인프라 없음(마크다운 1개), 그리고 출고.
