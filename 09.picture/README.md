## 한 줄 설계

```
그룹핑(시간 창 + 유사도) → 그룹별 피처 벡터 → score = w · f → 추천 1장 표시
사용자가 직접 1장 선택 → (피처, 추천, 선택) 로그 → 쌍 비교 학습으로 w 갱신
```

- 1사이클: 손으로 정한 w, 로컬 휴리스틱, 로그 수집, 삭제 없음, APK 1명 전달
- 2사이클: 유저 얼굴 등록과 주인공 판별 피처 추가
- 3사이클: 로그로 w 개인화, 섀도 모드로 검증
