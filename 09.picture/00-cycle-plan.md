# 사이클 계획

원칙: 1사이클 = 1출고. 로컬에서만 도는 것은 출고가 아니다. 마감 시점 상태 그대로 내보낸다.

## 1사이클 (4시간, Android)

**출고물**: 화면 1개짜리 Android 앱 APK를 다른 사람 1명의 폰에 설치.

**기능**
1. 갤러리 읽기 권한 요청 (`READ_MEDIA_IMAGES`)
2. 최근 500장 로드 (MediaStore, `DATE_TAKEN` 내림차순)
3. 촬영 시각 10초 이내 + dHash 해밍 거리 ≤ 10 으로 그룹핑 (`01-grouping.md`)
4. 그룹마다 피처 계산: 전체 선명도, 얼굴 수, 눈 뜸 최소값, 미소, 얼굴 크기 (`02-quality-features.md`)
5. 손으로 정한 가중치로 점수, 그룹당 1장에 "추천" 배지
6. 사용자가 그룹을 열어 직접 1장 선택 → 로컬 DB에 로그 저장 (`04-preference-learning.md`의 로그 스키마)
7. 삭제 없음. 삭제는 2사이클.

**하지 않는 것**: 유저 얼굴 인식, 학습, 서버, 설정 화면, 아이콘, 온보딩.

**출고 기준**: 받은 사람이 설치해서 그룹 목록을 보고 한 그룹에서 한 장을 고를 수 있으면 끝.

**회고 데이터**: 추천과 선택이 일치한 비율. 불일치 그룹의 공통점.

## 2사이클 (며칠 이내)

- 유저 얼굴 등록 (셀카 3장) + MobileFaceNet 임베딩 (`03-identity-protagonist.md`)
- 피처에 `user_face_present`, `user_face_quality` 추가, 가중치 압도적으로 크게
- 삭제 기능 (`MediaStore.createDeleteRequest`, 시스템 확인창)
- 다시 같은 1명 + 새 1명에게 전달

## 3사이클

- 로그 수십 개 이상 쌓인 뒤, 쌍 비교 로지스틱으로 w 개인화
- 섀도 모드: 새 w의 선택을 숨기고 실제 선택과 일치율 비교
- 추천 없이 보여주는 그룹을 5개 중 1개 섞어 편향 없는 평가셋 확보
